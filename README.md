# Dotfiles Configuration ✨

This repository contains my personal configurations for various tools and applications,
organized for easy setup and management across systems using `stow`.

## Overview 🌟

- **Neovim** (`nvim`): Native `vim.pack` based configuration with the built-in LSP client.
- **Tmux** (`tmux`): Config split into modules (theme, statusline, utility), plugins managed by TPM.
- **Ghostty** (`ghostty`): Terminal config, including a custom cursor smear shader.
- **Zsh** (`zsh`): `.zshrc` (Oh My Zsh, fnm, pyenv, pnpm) and `.zprofile`, portable across macOS and Linux.
- **Git** (`git`): `.gitconfig` using the `gh` credential helper.
- **OpenCode** (`opencode`): `AGENTS.md` and the MCP config. Skills, commands and plugins are
  generated by the gentle-ai installer and are not tracked here.

## 📁 Structure

```plaintext
dotFiles/
├── ghostty/    # Ghostty configuration and shaders
├── git/        # .gitconfig
├── nvim/       # Neovim configuration
├── opencode/   # OpenCode AGENTS.md and MCP config
├── tmux/       # tmux configuration
├── zsh/        # .zshrc and .zprofile
└── install.sh  # Package install + stow bootstrap (macOS and apt-based Linux)
```

Each folder mirrors the home directory layout (e.g. `nvim/.config/nvim`), so `stow`
can symlink it into place.

## 🚀 Installation

### Quick start ⚡

```bash
git clone git@github.com:kete102/dotFiles.git ~/dotFiles
cd ~/dotFiles
./install.sh
```

`install.sh` installs the packages (Homebrew on macOS, apt on Pop!_OS/Ubuntu), Oh My Zsh and TPM,
then links everything with `stow`. Pass `--no-packages` to only run `stow`. If `stow` reports
conflicts with existing files, move them away (or use `stow --adopt <package>`) and run it again.

The manual steps below do the same thing by hand.

### 1. Install GNU Stow 📦

```bash
# macOS
brew install stow

# On Debian/Ubuntu
sudo apt install stow

# On Arch Linux
sudo pacman -S stow
```

### Requirements (Linux / Pop!_OS) 🐧

The configs work on both macOS and Linux. On Pop!_OS, install these first:

```bash
sudo apt install stow tmux ripgrep fd-find build-essential nodejs npm \
  wl-clipboard   # Wayland (COSMIC); use xclip on X11
```

- **Neovim 0.12+**: the config uses `vim.pack` and `vim.lsp.config`. The apt package is too old,
  so install it from the [official release](https://github.com/neovim/neovim/releases) (tarball or AppImage).
- **lazygit**: not in the default apt repos, install it from its [releases](https://github.com/jesseduffield/lazygit/releases).
- **Ghostty**: see the [install docs](https://ghostty.org/docs/install/binary).
- **IosevkaTerm Nerd Font**: install it into `~/.local/share/fonts` and run `fc-cache -f`.
- **tmux clipboard**: `y` in copy-mode uses `pbcopy` (macOS), `wl-copy` (Wayland) or `xclip` (X11)
  automatically.

### 2. Clone the Repository 💍

Clone the repository to your home directory:

```bash
git clone git@github.com:kete102/dotFiles.git ~/dotFiles
```

### 3. Use Stow to Apply Configurations 🛠️

```bash
cd ~/dotFiles
stow nvim
stow tmux
stow ghostty
stow zsh
stow git
stow --no-folding opencode
```

This will:

- Link Neovim configurations to `~/.config/nvim` 📝
- Link tmux configurations to `~/.config/tmux` 🛋️
- Link Ghostty configurations to `~/.config/ghostty` 👻
- Link `.zshrc`, `.zprofile` and `.gitconfig` into `~` 🐚
- Link OpenCode configuration to `~/.config/opencode` (`--no-folding` keeps generated files out of the repo) 🤖

### 4. Install tmux plugins 🔌

Plugins are not stored in this repo. Install [TPM](https://github.com/tmux-plugins/tpm)
where `tmux.conf` expects it, then press `prefix + I` inside tmux:

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```
